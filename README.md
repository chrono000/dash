# HollaEx Dashboard

The dashboard for [HollaEx](https://hollaex.com), consisting of a **server** (API backend) and a **client** (frontend).

## Structure

```
dashboard/
├── server/   # Node.js API server (Express, PostgreSQL, Redis)
└── client/   # Frontend application
```

## Server

The backend API built with Express, Swagger 2.0, Sequelize, PostgreSQL, and Redis. See [`server/README.md`](server/README.md) for setup and usage details.

## Client

The frontend application for the dashboard. See [`client/README.md`](client/README.md) for setup and usage details.

## Getting Started

Refer to each subdirectory's README for prerequisites and quick-start instructions:

- [Server setup](server/README.md)
- [Client setup](client/README.md)
